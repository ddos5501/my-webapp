사전검토 & 모델 선정 완료
1. 데이터와 목적의 머신러닝 적합성 (LLM 검토)

대학생의 스트레스 지수, 수면 시간, 카페인 섭취량, 운동 횟수, 과제 부담도는 자율신경계 및 식욕 조절 호르몬(코르티솔·그렐린·렙틴)에 복합적(비선형적)으로 작용하므로 단순 규칙보다 머신러닝 분류 모델 적용에 매우 적합함.

2. 입력변수·정답변수 설정 및 분류 문제 여부

• 입력변수(X, 5개): 학업스트레스지수, 일평균수면시간, 일일카페인섭취량, 주간운동횟수, 전공과제부담도
• 정답변수(Y, 1개): 식욕변화유형 (식욕 증가, 변화 없음, 식욕 감소) → 다중 분류(Multi-class Classification) 문제

3. LLM 추천 모델 및 최종 모델 선택 이유

• LLM 추천: 랜덤 포레스트(Random Forest) 및 의사결정나무(Decision Tree)
• 최종 선택: 랜덤 포레스트 분류 모델 (단일 결정나무 대비 과적합을 방지하고 테스트 정확도 92.5%, 훈련 정확도 95.0%로 가장 우수한 일반화 성능을 달성함)

4. 핵심 결과 해석 및 제작 과정 개선 사항

• 결과 해석: 스트레스 6~8점 구간에서는 수면 부족과 결합해 '식욕 증가(보상성 섭식)'가 우세하나, 9~10점의 극심한 급성 스트레스+고카페인(3.5잔↑) 구간에서는 교감신경 항진으로 오히려 '식욕 감소'가 나타남.
• 수정·개선: 초기 계획의 '야식 빈도' 변수는 정답(식욕 증가)과 직결되는 데이터 누수(Data Leakage) 우려가 있다는 LLM 자문을 반영해 '전공과제부담도'로 대체하여 모델 신뢰도를 개선함.
