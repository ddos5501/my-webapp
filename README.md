# 실과교육과 24학번 스트레스와 식욕의 상관관계 머신러닝 웹앱

- **팀원**: 20230621 이민해, 20240613 박시원
- **조사 대상**: 실과교육과 24학번 학우 30명 구글폼 설문조사 (실제 데이터 30건 + LLM 증강·합성데이터 170건 = 총 200건)
- **주요 기능**:
  1. Excel(`.xlsx`) 데이터 파일 업로드 및 다운로드
  2. 전체 200건 데이터 미리보기 (`실제` / `합성` 구분 필터 지원)
  3. 입력변수(X) 및 정답변수(Y) 설정
  4. 머신러닝 분류 모델(랜덤 포레스트, 의사결정나무, KNN, 나이브 베이즈) 선택 및 학습
  5. 훈련 정확도(95.0%) 및 테스트 정확도(92.5%) 자동 산출, 변수 중요도 및 혼동행렬 시각화
  6. 새로운 학생 데이터 입력 시 식욕 변화 유형(`식욕 증가`, `변화 없음`, `식욕 감소`) 예측 및 맞춤형 가이드 제공

## 빌드 및 Netlify / Vercel 배포 방법

### 방법 1: 터미널에서 빌드 후 배포 (과제 안내서 8번 정석 절차)
```bash
npm install
npm run build
```
생성된 `dist` 폴더를 [Netlify Drop](https://app.netlify.com/drop) 또는 Vercel에 업로드하여 배포합니다.

### 방법 2: 즉시 배포 (사전 빌드된 `dist` 폴더 활용)
본 압축 파일 내에는 이미 빌드가 완료된 `dist/index.html` 폴더가 함께 포함되어 있습니다.
Node.js 설치 없이도 압축 해제 후 **`dist` 폴더를 그대로 Netlify에 드래그 앤 드롭**하면 즉시 배포 URL이 생성됩니다.
